# Shak Clips Studio

The toolkit behind the daily Shak Clips uploads: a 2D stick-figure animation engine (Canvas + Playwright), free Kokoro narration, synthesized music and SFX, thumbnail builders, and a vertical Short maker.

- `RUNBOOK.md`: the daily procedure the scheduled run follows.
- `topics.md`: the topic queue. Add topics here.
- `log.md`: what each daily run made.
- `engine/`, `tts/`, `thumb/`: tools. `examples/`: two finished videos (script + shots) to copy from.
